# MultiSafío 1.0.13

Hotfix de estabilidad para instalaciones nuevas.

- Corrige el cierre durante la carga inicial de resource packs con el error `Image is not allocated`.
- Sustituye la transformación de imágenes problemática de CustomSkinLoader 14.28 por una compilación compatible con Forge 1.20.1.
- Conserva la corrección de perfiles necesaria para mostrar correctamente las skins de otros jugadores en multijugador.
- Mantiene FancyMenu, Embeddium, Oculus, los resource packs y la configuración visual existente.

La actualización elimina automáticamente el archivo anterior de CustomSkinLoader para impedir que queden dos versiones instaladas.

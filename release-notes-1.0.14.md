# MultiSafío 1.0.14

Actualización de herramientas, cámaras y estabilidad para cliente y servidor.

- Añade **Another Admin Panel (AAP) 1.4.1** para las herramientas de administración aprobadas.
- Añade **CMDCam 2.2.1** para crear recorridos de cámara y escenas dentro de Minecraft.
- Retira **ModTools**, que causaba incompatibilidades al cargar el paquete en el servidor.
- Incluye la configuración inicial de AAP y conserva el menú, las skins, las misiones, las ruletas y los eventos existentes.
- Incluye los perfiles preparados para probar BSL y MakeUp Ultra Fast con el cielo personalizado.

La versión se comprobó desde una instalación limpia con Forge 47.4.20 hasta llegar correctamente al menú principal. El parche conserva los mundos y los datos personales de cada jugador.

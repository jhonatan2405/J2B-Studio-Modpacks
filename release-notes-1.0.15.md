# MultiSafío 1.0.15

Actualización de optimización, control de criaturas y herramientas para administración.

- Añade **Collections Of Optimizations 5.0** en cliente y servidor.
- Añade **OhHayden's Mob Control 2.0.1-beta-2** con una base neutra: no modifica todavía las apariciones hasta que se creen reglas para eventos.
- Añade **More Sticks 1.0.0** como herramientas creativas para la administración; esta versión no incorpora recetas de supervivencia.
- Conserva las misiones, ruletas, eventos, mundo y configuraciones existentes.

La versión se comprobó desde una copia limpia con Forge 47.4.20 hasta llegar al menú principal. El paquete dedicado también llegó a `Done` y se apagó limpiamente. El parche conserva los mundos y los datos personales de cada jugador.
